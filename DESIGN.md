# Корона и Сталь — дизайн-документ

Браузерный кликер + idle в стиле «меча и магии». Игрок — король, которому суждено поднять
своё королевство: добывать ресурсы, строить город, ковать оружие, нанимать авантюристов
и отправлять их оборонять ворота и зачищать подземелья.

## Ответы на вопросы (основа концепции)

| Тема | Решение |
|---|---|
| Главный цикл | Кликер + idle: волны монстров у ворот, добыча материалов, развитие города, наём и снаряжение авантюристов, задания (оборона ворот, зачистка подземелий) |
| Кто игрок | Король. Нанимает людей разных профессий, управляет городом и гильдией |
| Графика | Пиксель-арт |
| Платформа | В основном ПК-браузер |
| Что делает клик | 1) Добыча ресурсов: король «сам взял кирку», потом всё автоматизируют рабочие. 2) Урон в бою у ворот, зависит от оружия короля |
| Волны | Игрок сам вызывает волну, когда готов |
| Поражение у ворот | Средний штраф: монстры грабят часть ресурсов, ломают здание (оно теряет уровень), авантюристы могут погибнуть |
| Темп | Средний: задания длятся от минут до получаса |
| Ресурсы | Базовые (золото, дерево, камень, железо), редкие металлы (мифрил), части монстров (кости), магические (мана-кристаллы) |
| Крафт | Рецепты + случайная редкость (обычный → легендарный) |
| Авантюристы | Классы, редкость при найме, навыки и дерево развития |
| Жители | Рабочие, ремесленники, стража, советники, авантюристы |
| Подземелья | Этажи с решениями: атаковать / обороняться / бежать, идти глубже / вернуться. От решений зависит, выживет ли отряд |
| Решения в подземелье | Если игрок в игре, отряд спрашивает его. Если нет, действует по заранее отданному приказу |
| Долгосрочная цель | Всё вместе: кампания с финальным боссом, затем династия (престиж) |
| Сюжет | Пока без сюжета |
| Король | Своё снаряжение, заклинания, прокачка, указы-приоритеты (что исследовать и строить первым) |
| Город | Пиксельная карта с фиксированными слотами под здания |
| Язык | Русский + English |

## Первая версия (ядро) — что сделано

- **Карта города со слотами**: Замок, Лесопилка, Каменоломня, Шахта, Кузница, Таверна, Казармы, Главные ворота, Подземелье за стеной.
  Спрайты зданий меняются с уровнем (уровни 1–2, 3–5, 6+).
- **Клики**: по Замку собираются налоги (золото), по Лесопилке, Каменоломне и Шахте добываются ресурсы. Клик по Кузнице подгоняет ковку.
- **Рабочие** автоматизируют добычу. Уровень здания даёт больше мест и выше выработку.
- **Королевская кирка**: улучшение силы клика при добыче.
- **Королевский рынок** в Замке: продать половину запаса материала за золото (золото — главный дефицит экономики).
- **Кузница**: 3 тира (железо, кость, мифрил) × 5 предметов (меч, лук, посох, булава, броня).
  Редкость случайна: Обычный, Добротный, Редкий, Эпический, Легендарный. Редкие и выше получают бонусные свойства, легендарные — собственное имя.
  Уровень кузницы и кузнецы повышают шанс редкости и скорость.
- **Таверна**: случайные кандидаты (Новичок, Ветеран, Герой, Легенда), 4 класса: Воин, Лучник, Маг, Жрец.
- **Снаряжение**: оружие под класс и броня для любого класса. Король может носить любое оружие, от него зависит урон клика в бою.
- **Казармы**: стража стреляет со стены во время волн.
- **Ворота**: игрок сам вызывает волну. Бой идёт в реальном времени: монстры идут к воротам, стража и авантюристы бьются, король кликает по монстрам.
  Каждая 5-я волна — босс.
  Поражение: −15% ресурсов, одно здание теряет уровень, павшие защитники могут погибнуть (снаряжение погибших у ворот возвращается в арсенал).
- **Подземелье «Катакомбы»**: этажи без конца, каждый 5-й с боссом. На каждом этаже враг, на выбор атака, оборона или бегство.
  Показываются шансы на победу. После боя на выбор: глубже или домой. Добыча едет в рюкзаке и доставляется, только если отряд вернулся.
  Если отряд разбит, добыча теряется, часть бойцов гибнет, **снаряжение павших в подземелье теряется**.
  Приказы: Напролом, Взвешенно, Осторожно, плюс максимальный этаж. Если игрока нет или он не ответил за 20 секунд, отряд действует по приказу.
- **Офлайн-прогресс** до 8 часов, автосохранение в браузере (localStorage), экспорт и импорт сохранения.
- **Цели-подсказки** для обучения, переключатель RU/EN.

## Дорожная карта (следующие версии)

1. **Исследования и указы**: академия с деревом исследований. Указы короля задают приоритеты: что исследовать, что строить первым (очередь строительства с таймерами).
2. **Дерево навыков авантюристов**: очки за уровень, ветки по классам.
3. **Прокачка короля**: уровень, таланты (Воин, Строитель, Торговец), заклинания с перезарядкой (метеор, исцеление, «золотая лихорадка»).
4. **Советники**: казначей, придворный маг, маршал с пассивными бонусами.
5. **Новые подземелья** и карта мира, новые монстры и материалы, зачарование рунами.
6. **Кампания**: пробуждение финального босса и финальная битва.
7. **Династия (престиж)**: новая эпоха с бонусами наследника и повышенной сложностью.
8. Звук и музыка, баланс, мобильная раскладка.

## Технически

- Чистый HTML + CSS + JavaScript, без сборки и зависимостей. Папка `game/`.
- Вся пиксельная графика рисуется кодом (`js/sprites.js`), внешних картинок нет.
- Запуск: открыть `game/index.html` в браузере. Если включить GitHub Pages для репозитория, игра будет доступна по адресу `/game/`.
