# Король мира (King of the World)

Idle + RPG.

Браузерный RPG-кликер в стиле «меча и магии». Ты король, у которого есть только замок и 10 дерева.
Нужно собрать налоги, построить лесопилку и вырастить королевство:
- кузница, таверна и стены;
- волны чудовищ у ворот;
- подземелья с пошаговым боем;
- академия и указы;
- в финале — битва с Древним драконом.

## Как запустить

Открой `index.html` в браузере, сборка не нужна. Игра сохраняется в браузере сама.

Чтобы играть по ссылке, включи GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

## Устройство

- `index.html`, `css/style.css` — страница и стили.
- `js/` — модули игры:
  - экономика, кузница, таверна, бой у ворот, подземелья, исследования, король;
  - интерфейс и тексты на русском и английском.
- Пиксель-арт рисуется кодом (`js/sprites.js`), звук синтезируется (`js/audio.js`): внешних картинок и файлов нет.
- `DESIGN.md` — дизайн-документ: ответы на вопросы, решения по версиям, темп игры.
- `LICENSE` — Apache License 2.0.
