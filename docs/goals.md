# Цели «Короля мира» — для правки

Все 115 целей игры (версия 1.1.0-dev) по порядку. Под картой видны 3 цели подряд:
игрок принимает цель, выполняет и сдаёт за награду.

Как править:
- Цель — текст, который видит игрок. Меняй как хочешь.
- Нужно — число для целей с прогрессом (например, «собери 30 дерева»).
- С принятия — «да»: прогресс считается с момента, когда цель приняли, а не за всю игру.
- Награда — ресурсы и количество: золото, дерево, камень, железо, кости, кристаллы, мифрил, адамантий.
- Проверка — как игра понимает, что цель выполнена. Другое условие — опиши словами в «Комментарии».
- Куда ведёт — куда перекидывает кнопка цели.
- Порядок — порядок блоков: переставь блок, чтобы поменять очередь.
- Удалить — удали блок или напиши «удалить» в комментарии.
- Новая цель — добавь блок, в ID напиши «новая», условие опиши словами.
- ID не меняй: по нему переносится прогресс у тех, кто уже играет.
- Английские тексты я обновлю сам по русским.
