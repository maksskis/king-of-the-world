# Цели «Короля мира» — для правки

Выгрузка всех 115 целей из игры (версия 1.1.0-dev). Под картой видны 3 цели подряд по порядку этой таблицы:
игрок принимает цель, выполняет и сдаёт за награду.

## Как править

- **Цель** — текст, который видит игрок. Меняй как хочешь.
- **Нужно** — число для целей с прогрессом (например, «собери 30 дерева»). Можно менять.
- **С принятия** — «да»: прогресс считается с момента, когда цель приняли (а не за всю игру).
- **Награда** — ресурсы и количество, например «50 золото, 20 дерево». Ресурсы: золото, дерево, камень, железо, кости,
  кристаллы, мифрил, адамантий.
- **Что проверяется** — как игра понимает, что цель выполнена. Если нужно другое условие — опиши словами в «Комментарии».
- **Куда ведёт** — куда перекидывает игрока кнопка цели.
- **Порядок** = порядок строк. Переставляй строки, чтобы поменять очередь.
- **Удалить** цель — удали строку или напиши «удалить» в комментарии.
- **Новая** цель — добавь строку, в ID напиши «новая», а условие опиши словами.
- **ID** не меняй — по нему переносится прогресс у тех, кто уже играет.
